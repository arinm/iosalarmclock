Troubleshooting

My alarm didn’t ring

Make sure Punctual has permission to ring alarms: open Settings in the app and check that Alarms (AlarmKit) shows “On”. Alarms ring on the device they’re scheduled on; keep the app installed and open it occasionally so upcoming alarms stay scheduled.

I didn’t get the heads-up notification

Heads-ups are notifications - make sure Heads-up notifications is “On” in the app’s Settings (and in iOS Settings → Notifications). Alarms still ring even if notifications are off.

I bought Pro on another device

Open the upgrade screen and tap Restore Purchases.

Custom heads-up sound won’t import

Import an audio file you own (Files, Voice Memos, etc.). Apple Music tracks are protected and can’t be used. The first 30 seconds are used. The imported sound plays with the heads-up; the alarm itself uses the system alarm sound.
